| CI Security Scan | Passed on `1641b29b` |

**What #1453 exposes.** The receipt adds no personal data to the API. The
prompt page fetches only from a fixed `raw.githubusercontent.com` prefix.
The hash is validated as 64 hex characters before any fetch, so a path can't
be injected. The text is shown only if its sha256 matches its name. Each
fetch is bounded by a 5-second timeout. Source links are restricted to
http(s).

**What #1449 changes.** The server-wide upload limit rises from 50 MB to
3 GiB. To keep that from widening user uploads, `documents` (signed-URL
uploads, where storage is the only size check) gets an explicit 50 MB bucket
limit, and so does every other bucket without one.
