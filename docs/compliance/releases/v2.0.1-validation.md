## 2. Semver

**Patch.** There is no GraphQL schema change and no Prisma migration. No
backend `package.json` changed; the root gained one override
(`@node-minify/core>glob`), and the lockfile changed with #1437's frontend
adapter upgrade.

The one migration-directory change, `supabase/migrations/99_vault_functions.sql`,
revokes `EXECUTE` on three Vault RPCs from `PUBLIC`, `anon` and
`authenticated`. That closes an exposure rather than changing a contract,
since every app path calls them as `service_role`.

**Operator-visible change:** a node that relied on the seed's dev defaults
must now set `SEED_DEV_DEFAULTS=true` (the UAT, integration and e2e compose
files do), or supply `SEED_ADMIN_PASSWORD`. Production depends on neither.

| `gitleaks detect --source . --no-banner` | No leaks (1,465 commits, as gitleaks counts them) |

**Fixed by this release:** the Vault RPCs were executable by `anon`,
`authenticated` and `PUBLIC`, so any client of the Supabase API holding the
public anon key could read and rewrite every Vault secret.

**Production was closed by hand on 2026-11-13**, before this tag, with the
release's own `REVOKE`, and checked: only `postgres`, `service_role` and the
owner keep `EXECUTE`. Kong's logs since its last start (2026-11-01) show
5,931 Vault RPC calls, all from the app's own containers and none from
outside. Vault's last write was Window A's deploy seed (2026-11-09 03:34
UTC). Logs before 2026-11-01 are gone, so there's no evidence either way for
that period.

## 7. Regulated-data handling

`scripts/data-scan.ts --all` on `ced2a8f4`: **passed**, with 25 non-blocking
`medium` findings, all of them email reaching a log in the auth flows, all
carried (EX-13). That's one fewer than `v2.0.0`: the admin bootstrap's email
log left `db-migrate.sh` with #1442. **No critical or high finding is open.**

**The corpus transfer and personal data.** The export reads civic tables
only, so no dev account reaches production, and no production user data
leaves the Studio. The swap locks the user tables, counts them before and
after, and refuses unless they're identical. It refuses any
cascading user reference that finds no match. Its reports carry counts and
identifiers only.

**Runtime trust boundary:** unchanged. Inference is self-hosted on the node
(`CTL-HIPAA-002`-style posture). The development-time AI is qualified
separately (`CTL-AIQ-001`).

## 8. Risk

| Risk | Status |
|---|---|
| The swap loses or orphans user data | **Mitigated**: rehearsed on a prod copy with identical user counts; one transaction; W3 dump is the post-commit rollback |
| Swap locks wait on live services | **Mitigated**: `lock_timeout` 5 s, so it fails rather than waits. The runbook stops every app service first and checks the remaining sessions. G4 ran with no other sessions, so the timeout path is untested on prod |
