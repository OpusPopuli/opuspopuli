## 6. Regulated-data handling — `ca-personal-information`

**No personal data in scope.** This release moves AI instruction text from source
into a database. The templates contain no personal information, take no variables,
and process no user content — the image reaches the model through the request's
`images` array, never through template interpolation.

Indirect benefit to attestation: prompts served from prompt-service carry a version
and content hash, so an output produced from them can name the exact instruction
behind it. Prompt text inline in this repo cannot (see #1246).

`/op-data-scan` not run (E-7, carried).

## 9. Deploy

**Not required.** `getOcrTranscriptionPrompt` has no production caller — its only
consumer is the eval harness, which is development tooling and ships in no image.
No migration, no schema change, no configuration change. The tag exists so the
release history keeps tracking `main`.

If deployed anyway: prompt-service must be **reseeded** for the new templates to
exist (#605 — deploying does not reseed). Nothing in production reads them, so this
is not urgent.

**Unaffected by this release, and still outstanding:** `v1.25.0` must reach the node
**before** `frontend-v1.13.0`. That constraint belongs to the previous release and
is unchanged here.
