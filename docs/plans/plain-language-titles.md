# Plain-language titles for measures — design, and the limits on it

**Status:** proposal. Nothing built. Default is OFF and stays OFF until §6 passes.
**Touches:** #1219 (summary quality), #1143 (prompt attestation), #849 (neutrality validator)

## 1. The problem

Official ballot-measure titles are written by institutions, for institutions.
One from the live corpus:

```
LIMITS ABILITY OF VOTERS TO RAISE REVENUES FOR LOCAL GOVERNMENT SERVICES.
INITIATIVE CONSTITUTIONAL AMENDMENT.
```

A voter holding a petition sheet should be able to read what it does. That is
the whole product thesis, so making this legible is squarely on-mission.

## 2. Why this is sensitive ground, stated plainly

California Attorney General title-and-summary wording is **routinely
litigated**. Proponents sue over it. The titles are contested precisely because
wording moves votes, and the example above is not neutral phrasing — whether
you think it is depends on what you think of the measure.

So the moment we rewrite it, we become a **second editorial voice on contested
language**. "The AI softened it" / "the AI sharpened it" is easy to allege and
expensive to disprove, and the accusation does not need to be true to cost us.

This is the `project_unassailability_standard` case in its sharpest form. The
resolution is not to avoid the feature — illegible civic text is its own
failure — but to make the editorial act **visible, attributable, and
reversible**.

## 3. The house pattern already decided this

`packages/common/src/providers/region/civics-types.ts`:

> "AI rewrite for a typical voter. **Never replaces verbatim.**"

`CivicsBlock` already stores verbatim source text and a plain-language rewrite
together, and `prompt_hash` / `prompt_version` columns already exist on AI
output rows. This is an extension of a decided pattern to a new surface, not a
new idea.

## 4. Design

### 4.1 Both, always. Never a replacement

Two fields, never one overwriting the other:

| Field | Source | Shown as |
|---|---|---|
| `title` | verbatim, as filed | subtitle |
| `plainTitle` | AI rewrite | headline |
| `plainSummary` | AI rewrite of the measure's effect | body |

The verbatim text is never mutated and never absent. If the rewrite is
missing, the surface degrades to exactly what it renders today.

### 4.2 Provenance is SYMMETRIC

The trap is labelling the AI text and leaving the original unlabelled, which
silently frames the original as neutral ground truth. It is not — it is also an
authored artefact with an interested author.

Both get a source line:

- *"Plain-language summary generated by Opus Populi · prompt v3 · a1b2c3d"*
- *"Official title as written by the California Attorney General"*

Symmetry is the property to test: a reader must be able to tell who wrote each
string, and that must be true of both strings.

### 4.3 NEVER embed the rewrite

**The retrieval source stays verbatim.** A petition scan photographs the AG's
actual words off the sheet; matching that against a paraphrase compares unlike
things, and `PropositionEmbeddingService.embeddingSource` already reasons from
exactly this principle.

This is the constraint most likely to be violated by accident, because the
rewrite *would* be cleaner embedding input than today's title-echo text
(#1219). It would also quietly sever the link between what the camera sees and
what the corpus holds. Display and retrieval are different jobs.

### 4.4 Generation is pinned, never silent

Store `promptHash`, `promptVersion` and the model on the row. Regenerate only
on an explicit version bump — **never** on a model swap, a cache miss, or a
redeploy. A voter must not see a different title for the same measure two weeks
running; instability is itself a credibility problem.

### 4.5 Neutrality guard, reusing what exists

#849 Phase 2 already scans LLM output for persuasive vocabulary and falls back
to a deterministic template on any match. Same shape here, with the ideal
fallback available: **fall back to the verbatim title.** Failure mode is "the
reader sees the official wording", which is where they are today.

### 4.6 Both languages

English and Spanish, or Spanish speakers get institutional wording while
English speakers get the readable version. That is an equity gap, not a polish
gap.

## 5. Configuration — cautious by default

```
MEASURE_TITLE_MODE = verbatim | plain_secondary | plain_primary
```

- **`verbatim`** — DEFAULT. Exactly today's behaviour. Nothing generated is
  displayed. The feature ships dark.
- **`plain_secondary`** — verbatim stays the headline; the rewrite appears
  below it. The low-risk middle setting, and the one to run first.
- **`plain_primary`** — the rewrite is the headline, verbatim becomes the
  subtitle. What #1219's discussion originally proposed.

Defaulting to `verbatim` means enabling this is a deliberate, recorded act
rather than a consequence of deploying. Generation can run and be inspected in
the database long before anything renders.

## 6. The gate before any of this renders

Generate for all 64 propositions and measure, in the eval harness:

1. **Identifiability** — can a reader pick the correct measure from the
   rewrite alone? A rewrite that loses the subject is worse than institutional
   prose.
2. **No added stance** — run the #849 forbidden-vocab scan over all 64 and
   report the hit rate, not just a pass/fail.
3. **No dropped effect** — the rewrite must not omit what the measure *does*.
   Vagueness is the likely failure of a plain-language pass, and it is the one
   that reads as neutral while being less informative.
4. **Diff against verbatim** for the subset where the official title is
   *already* clear. Some are. A rewrite that makes those worse is a regression
   the average will hide.

If (1)-(4) do not pass convincingly, this stays at `verbatim` and we have lost
nothing but the generation cost.

## 7. Open questions

- Does the rewrite belong on bills too, or only measures a citizen is asked to
  sign? Bills are less contested and more numerous.
- Should `plain_primary` be available per-region, given that AG-title politics
  is a California-specific fight?
- Who countersigns a wording change once this is live? A prompt edit becomes an
  editorial decision about contested civic text.

## 8. What this is NOT

Not a summarizer for long documents, not a recommendation engine, and not a
substitute for reading the measure. The verbatim text stays one line away at
all times.
